### 📐 RAG Pipeline Architecture

```
[Documents] → [Parser] → [Chunker] → [Embedder] → [Vector DB]
                                                         ↓
[User Query] → [Query Embedder] → [Retriever] → [Re-ranker] → [LLM] → [Response]
```

**Key Components:**
- **Parser:** Unstructured, LlamaParse, PyMuPDF, Docling
- **Chunker:** RecursiveTextSplitter, Chonkie, Semantic Chunker
- **Embedder:** OpenAI ada-002, BGE, E5, Nomic-embed
- **Vector DB:** Chroma, Qdrant, Milvus (choose above)
- **Retriever:** BM25, Dense, Hybrid
- **Re-ranker:** Cohere Rerank, BGE-reranker, Jina Reranker
- **LLM:** Any (local or API)
